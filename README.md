# Fullstack Product Manager - Shindy

A full-stack product management application built with:

- **Frontend:** React
- **Backend:** Express
- **Database:** MongoDB

## Features
- ✅ Add Product
- ✅ Edit Product
- ✅ Delete Product
- ✅ View All Products

## How to Run

1. Clone the repository
2. Install dependencies: `npm install` in both `backend` and `frontend` folders
3. Set up MongoDB Atlas
4. Run backend: `cd backend && node server.js`
5. Run frontend: `cd frontend && npm start`
